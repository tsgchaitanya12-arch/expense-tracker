# 🧾 Ledger — A Receipt-Style Expense Tracker

Ledger is a simple FinTech web app that lets you log everyday purchases and
instantly see where your money is going — styled like a printed shop receipt.

Built for [Hackathon Name] by [Your Name].

## The problem

Most people don't track small everyday spending (coffee, snacks, rides) because
budgeting apps feel like homework. Ledger makes tracking an expense feel as
quick and satisfying as ringing up an item at a register.

## Features

- **Add an expense** in seconds: item name, amount, and category
- **Running total** updates instantly as you add purchases
- **Spending breakdown by category** shown as simple bar meters
- **Data persists** between visits using your browser's local storage
- **Delete** any entry with one click
- Fully responsive — works on mobile and desktop

## Tech stack

- HTML, CSS, and vanilla JavaScript (no frameworks, no build step)
- `localStorage` for saving data in the browser

## How to run it

1. Clone this repo:
   ```
   git clone https://github.com/YOUR-USERNAME/expense-tracker.git
   ```
2. Open `index.html` in your browser. That's it — no installation needed.
